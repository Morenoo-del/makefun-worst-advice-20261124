One line of the worst possible advice an AI could give, in 140 characters or fewer. The program writes the line to `/output/entry.txt`; a house judge compares entries two at a time on funniness, tightness, AI voice, and how concrete the bad advice is.

## Run it

```sh
node main.ts
```

The entry is deterministic: every run writes the exact same line.
